# Site copy policy

Owner-controlled copy is the default for every site and brand in this repository.

- Do not invent promotional, descriptive, atmospheric, explanatory, SEO, or "helpful" brand copy.
- Visible prose should appear only when the owner supplied it or explicitly approved it.
- Prefer empty space over assistant-authored filler.
- Functional UI text is allowed when required for operation: navigation, form labels, buttons, validation/errors, status messages, accessibility text, safety/privacy disclosures, and concise instructions necessary to complete an action.
- Do not add taglines, eyebrow copy, hero paragraphs, section introductions, marketing headings, value propositions, calls-to-action beyond the required action label, or decorative explanatory text unless explicitly approved.
- When existing assistant-authored promotional copy is discovered, remove it rather than rewrite it.
- This rule applies to future pages, redesigns, new brands, admin tools, and public sites.
