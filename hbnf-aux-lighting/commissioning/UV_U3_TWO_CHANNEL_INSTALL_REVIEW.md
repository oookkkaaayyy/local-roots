## Hardware decision — prefer one rated, isolated CV PWM repeater without repowering SP803E

**REVIEW CANDIDATE:** LTECH LT-3040-5A four-channel CV PWM power repeater, use only channels 1 and 2. Manufacturer document: https://www.ltech.cn/uploads/pdf/en/LED-Controller/LT-3040-5A.pdf . It specifies **5–24V DC**, **5A/channel**, **PWM 200–2000Hz**, and **3kV optical isolation of signal input/output**, and shows one controller signal input driving separate load-side power supplies. Physical size approximately **175 × 44 × 30mm**. Do not infer whole-system galvanic isolation if the existing TOBSUN input/output grounds are connected. This is not a purchase recommendation without final fit/price/terminal verification, or proof that this particular input socket correctly accepts the installed SP803E common-positive low-side PWM waveform. **The manufacturer diagrams show isolated signal and load supplies but illustrate matching 12V/12V or 24V/24V examples; the exact proposed 12V controller PWM input with 5V lamp power is NOT explicitly manufacturer-qualified.** The signal-side `5–24V` product specification alone does not establish this mixed-rail use. If input polarity, reference and independent 5V load permission cannot be verified from the specific unit's rated instructions, do not connect; select a driver whose manufacturer explicitly qualifies those inputs instead. The SP803E terminals are MOSFET switched negative outputs, not bare 3.3V GPIO drive.

**Existing candidate reusable parts, subject to as-wired identification:** SP803E as currently 12V-fed, 22-group 12V WS2811 on GPIO16, existing TOBSUN EA50-5V converter feeding historical 5V UV lamps, two strips (previously measured short 0.52A and rim 0.80A at 5V), INIU single 12V/3A PD output, existing protected connectors/enclosure and previously recorded fuse. Existing 5A fuse cannot be assumed suitable for smaller branches/contacts. Current connection of 5V UV strips to AUX power is **owner-reported illuminated**, but as-built +/– distribution and polarity are NOT independently documented. Do not reuse the old disconnected label.

**Needed unless already owned and independently rated:** one electrically rated two-or-more-channel optoisolated repeater **explicitly compatible with the 12V SP803E PWM sink and independent 5V load supply** (above is the conditional candidate), manual **normally-open UV supply cutoff** physically interrupting the entire 5V UV power rail, separately qualified charger cover/UV exposure interlock and shielding, branch short-circuit protection rated against the smallest wire/connector, plus an independently fail-OFF/no-voltage-restart mechanism if the manual cutoff may remain ON through a battery restart. A latching ON rocker alone does **not** prove reset-OFF. Confirm actual enclosure fit and thermal room before any purchase; do not assume a bare GPIO or SP803E 12V PWM screw terminal can safely switch an independent 5V supply.

## Logical interconnection ONLY — not terminal-to-terminal wiring authorization

The desired **power-separated signal path** after unpowered as-built inspection is:

```text
Existing INIU 12V PD (one port) ─┬─ existing SP803E VCC/GND, unchanged
                                 ├─ existing 12V WS2811 + and GND, GPIO16 data unchanged
                                 └─ existing TOBSUN 12V→5V converter
                                        └─ approved 5V UV fuse + normally-OFF manual cutoff
                                             + exposure interlock/no-voltage-release gate
                                             └─ repeater load-side 5V supply / UV positives
SP803E 12V-side PWM3 (GPIO25) ── repeater INPUT channel 1 ── 5V switched rim UV negative
SP803E 12V-side PWM2 (GPIO26) ── repeater INPUT channel 2 ── 5V switched charger UV negative
(repeater input/common terminal pinout and optical isolation to be confirmed from actual unit)
```

**Do not execute this drawing as wiring instructions** until measured rails and manufacturer's *actual* PWM input common/polarity/current and terminal legend are accepted. **Logical channel mapping, not a terminal pinout:** the SP803E remains 12V powered, UV control PWM3/GPIO25 drives only repeater input A and PWM2/GPIO26 only repeater input B. A protected 5V output powers the repeater's load supply and UV positives behind the physical cutoff; repeater A/B switched returns independently drive UV negatives, replacing the existing unswitched bypass return. Input and output supplies must stay in their specified isolation domains, not be tied together by improvised terminal jumpers. In particular, do not tie the new repeater's 5V load outputs to the controller's 12V VCC, do not connect UV negatives to the old constant-ground bypass, do not bridge 12V+ to 5V+, and do not repower the SP803E at 5V to simplify the driver unless GPIO16/12V WS2811 interoperability is independently qualified. With currently unswitched UV power, merely configuring WLED segments will **not** dim or switch the strips.
